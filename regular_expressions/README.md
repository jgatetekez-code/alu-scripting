# Regular Expressions

This project contains Ruby scripts that practice using regular expressions.

## Task 0: Simply matching School

The script `0-simply_match_school.rb` searches for the word `School` in the given argument and prints every match.

### Usage

```bash
./0-simply_match_school.rb "Best School"
```

### Output

```text
School
```

The regular expression used is `/School/`.
