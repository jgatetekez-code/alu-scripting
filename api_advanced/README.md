
# Reddit API

## Description

This project uses the Reddit API to retrieve information about subreddits.

The Python function `number_of_subscribers()` returns the total number of subscribers for a given subreddit. If the subreddit is invalid, it returns 0.

## Requirements

- Python 3
- Requests library
- Internet connection

## Installation

Install the Requests library:

    pip install requests

## File

- 0-subs.py: Contains the number_of_subscribers function.
